      显示方式

      整页反色会让图片和图表一起变成负片，下面几项负责把它们还原成原本的配色。

      保留原本深色的区块
      深色导航条、深色页脚被反色后会变成亮块，在暗色页面上比原来还刺眼。开启这一项会把这类 区块恢复成本来的深色。
      图片 / 视频 / 画布保持原色
      默认开启。画布必须还原，否则 K 线图的红绿会颠倒。
      SVG 也保持原色
      默认关闭。内联 SVG 多为图标，跟随整页反色才能在暗底上看清；但用 SVG 绘制的 K 线图会因此红绿颠倒，需要精确配色时再开启。
      自定义修正 CSS

      反色方案在个别站点会有背景图被反色、固定定位元素错位之类的残留问题，可以在这里逐站补救。 这一段会追加到所有已启用站点的样式末尾，用 !important 即可覆盖。

      留空表示不追加。改动会在停止输入 500 毫秒后自动保存。
