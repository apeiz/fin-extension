入夜 Fall in Night
Chrome / Edge 扩展，Manifest V3

把网页收进夜色，
但不拖慢它。

指定几个网站，打开就是暗的。图片和视频保持原色，原本深色的区块不会被翻成亮块。 它不解析你的样式表，也不提交任何数据。

为什么它不会拖慢网页

市面上的暗色方案大多要先读懂页面：遍历样式表、判断每个颜色是背景还是文字、 生成一整套替换规则。这些工作跑在主线程上，而且必须在首屏绘制之前完成，页面自然变慢。

入夜走的是另一条路：不读样式表、不算颜色，只往页面里插一条 CSS 滤镜，交给浏览器的合成器处理。 代价是彩色会轻微褪色，换来的是几乎为零的启动成本。

它做了什么

整页变暗，图片保持原色

主规则把页面反色并旋转色相。照片、视频、画布再反转一次，回到原本的颜色，所以不会看到负片。

原本深色的区块保持深色

反色会把深蓝的导航栏翻成浅米色。扩展会找出这些区块再反一次，让它们回到深色，区块里的图片则不做二次处理。

标题位图不会被染灰

不少站点把大标题做成「透明底加深色文字」的图片。这类图片不参与还原，否则会变成深灰压在黑底上。

毛玻璃不会退化成亮斑

带 backdrop-filter 的导航栏反色后会糊成一块亮斑，所以统一关掉模糊，改用不透明度。

整屏 iframe 也会一起变暗

内容脚本注入到所有框架，站内嵌的页面不会在暗色里留一块白。

界面语言

目前只有中文界面。功能与浏览器语言无关，英文界面计划在后续版本补上。

已知限制

反色是像素级的后处理，它无法区分「一个好看的颜色」和「一个不好看的颜色」。 所以彩色会比原来淡一点，饱和度高的纯色（比如亮黄）会掉一截。 深色主题的站点再被反一次会变浅，这类站点建议加进白名单。

支持与联系
