# 入夜 Fall in Night

把网页收进夜色。

浏览器扩展版本。装上之后，列表里的网站每次打开就是暗色的，不用再回到网页上截图看效果。它和「入夜」的网页应用、桌面版共用同一套配色规则，所以在网页上预览到的效果，就是日常浏览时得到的效果。

先说清这个项目的定位。入夜不只是「让网页变暗」——这件事已有成熟的免费方案，做得比我们好。我们做的是**深色适配的评估与预览**：先看到暗下来是什么样，再决定要不要这么改。扩展是这条链路上最轻的一环，随手切一下，看一眼。

## 为什么它不会拖慢网页

让网页变暗有两条路：解析页面的样式表、把每个颜色重算一遍；或者不解析，直接给整页套一层滤镜。

入夜走后者。它不读 `CSSStyleSheet`、不算任何颜色、不生成替换样式表，只在页面最前面插一条规则：

```css
html { filter: invert(.92) hue-rotate(180deg); }
```

剩下的交给浏览器的合成器。所以打开页面时没有 JavaScript 在主线程上做样式分析，首屏不会因为扩展而延迟。包体积 30 KB，省掉的就是那套解析与颜色映射的代码。

代价写在明处：彩色会轻微褪色，红 `#d92b2b` 变成 `(184,67,67)`，色相保持但饱和度下降。纯灰阶（文字、边框）是精确的。这是拿色彩保真换来的轻。

## 安装

### 从商店安装

上架后在此补充 Edge Add-ons 链接。

### 开发者模式安装

1. 打开 `chrome://extensions/`（Edge 是 `edge://extensions/`）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本仓库目录

安装时会提示「读取和更改您在所有网站上的数据」。这条权限是必须的：扩展要在任意站点上注入样式，而站点列表由你随时增删，不能每加一个域名就重新授权一次。扩展只在命中列表的站点上动手，其余页面一行样式都不注入。

## 使用

- **工具栏图标**：总开关 + 当前站点开关。改动立即作用于已打开的页面，不用刷新。
- **管理站点列表**：弹窗右下角进入设置页。

设置页里：

| 操作 | 说明 |
| --- | --- |
| 所有网站入夜 | 默认**关闭**。打开后所有网站都会变暗，下面的站点开关随之失效（仅开关失效，效果已经全局生效） |
| 白名单 | 只在「所有网站入夜」打开时出现。列入的网站保持原样 |
| 添加 | 填域名或粘贴完整网址，会自动截成域名。输入已被现有通配规则覆盖的域名时只提示、不重复添加 |
| `*.example.com` | 覆盖该域及其所有子域（含裸域）。默认三条规则都用通配，因为子域经常承载 iframe |
| 精确域名优先 | 有了 `*.a.com` 全站开启，再单独加 `www.a.com` 关闭，`www` 就会被排除 |
| 单条开关 | 保留在列表里但临时不生效 |
| 图片 / 视频 / 画布保持原色 | 默认开。关掉后整页变成负片 |
| SVG 也保持原色 | 默认关。开启后 K 线类图表颜色精确，但内联 SVG 图标会跟着变深而看不清 |
| 保留原本深色的区块 | 默认开。深色导航条反色后会变成亮块，开启后恢复成本来的深色 |
| 自定义修正 CSS | 逐站补救个别的残留问题，会追加到所有已启用站点 |

## 站点数量

免费版可以保存 5 个站点、3 条白名单。只用两三个站的人永远碰不到上限；把浏览器里所有站点都改造一遍的人会撞上。

到上限时不会删任何已有条目，只是不能再新增。需要更多可以赞助换一个授权码，激活后不再限制数量。码不绑定设备，换电脑照样能用。

设这个上限的原因很直接：这个扩展没有广告、没有分析 SDK、不收集数据，也没有订阅，收入只有赞助一条路。不想赞助也完全不影响已保存的站点继续工作。

## 已知限制

这些是方案的边界，不是待修的 bug：

1. **视频站和需要精确原色的网站不适合。** B 站、YouTube、设计稿预览、看图站请用站点自带的深色主题，或用白名单排除。
2. **CSS 背景图会变成负片。** 大 banner、带纹理的卡片可能出现负片效果，可以用自定义 CSS 补救。
3. **白底图片在暗色页面上是亮块。** 图片保持原色是本扩展的取舍。
4. **彩色有轻微褪色。** 涨红 `#d92b2b` 会变成 `(184,67,67)`，色相正确但饱和度下降；纯灰阶（文字、边框）是精确的。红涨绿跌不会颠倒。
5. **原生下拉框仍是亮色。** 由浏览器绘制，扩展改不到。
6. **跨域 iframe 要单独加规则。** iframe 内部按它自己的域名判断是否生效。

更完整的技术说明与实测数据见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 三个形态

同一个项目还有两个形态，三者共用同一套配色规则。

| 形态 | 用途 | 状态 |
| --- | --- | --- |
| 浏览器扩展 | 随手预览、日常浏览 | 本仓库，MIT 开源 |
| 网页应用 | 输入一个网址，出原图与暗图的横拉对比 | 独立项目，暂不公开源码 |
| 桌面版 | 批量对比（4-6 页）与适配报告导出 | 开发中 |

配色规则在两处各有一份实现——扩展是静态文件，不能 `require` 外部模块，抽公共包要引入构建步骤，代价大于收益。两边靠一份共同的 CSS 快照基准对齐：扩展的测试断言当前输出等于快照，网页应用的测试对着同一份快照断言。任何一边改了规则而没同步，测试会失败。
